# Danger-time: kill the literal slow-motion interpretation first

Date: 2026-08-12

The intuitive observation that frightening moments can seem unusually long was one of the
original motivations for asking whether the biological present has a variable `width`.

There is a direct human negative control that should have been placed near the top of the
project from the beginning.

> **Fear-related retrospective time dilation does not imply increased perceptual temporal
> resolution.**

That substantially weakens the naive picture in which danger simply gives consciousness
more sensory `frames per second` or opens a longer perceptual shutter.

---

## 1. The free-fall experiment directly attacks the naive hypothesis

Stetson, Fiesta & Eagleman (PLoS ONE 2007, PMID `18074019`,
DOI `10.1371/journal.pone.0001295`) had participants undergo a 31 m free fall while
carrying a device designed to test visual temporal resolution.

The result contains the important dissociation:

```text
retrospective duration judgment
    participants judged their own frightening fall ~36% longer

visual temporal resolution during the fall
    no improvement over the relevant ground-based control
```

If subjective slow motion were literally caused by a ~36% increase in perceptual sampling
resolution, the visual discrimination measure should have improved correspondingly. It
did not.

The authors therefore favored a retrospective/memory explanation over a literal increase
in perceptual temporal resolution.

This is not the final word on every form of fear-related temporal distortion. The task
assays one visual resolution measure and one very particular frightening event.

But it is an unusually clean falsifier of the strongest version of our starting story:

```text
DANGER
  -> sensory clock speeds up
  -> more perceptual frames are experienced
  -> event therefore feels longer
```

That chain is not supported by this experiment.

---

## 2. Modern work makes `longer` itself non-unitary

Several recent experiments reinforce the need to stop treating subjective time as one
scalar.

### Duration versus felt passage

Lamprou-Kokolaki et al. (Consciousness and Cognition 2024,
DOI `10.1016/j.concog.2024.103635`) manipulated naturalistic event density.

More events could make an interval be judged **longer** while also making the **passage
of time feel faster**.

Bratzke (Attention, Perception, & Psychophysics 2026, PMID `41876805`,
DOI `10.3758/s13414-026-03241-8`) likewise found dissociation in an emotional-picture
experiment: arousal/valence affected passage-of-time judgments while duration judgments
did not show the same pattern in that stimulus set.

So at minimum separate:

```text
estimated duration
felt speed / passage of time
perceptual temporal resolution
```

They need not move together.

### Internal event structure

Wen, Yousif & Sherman (Cognition 2026,
DOI `10.1016/j.cognition.2025.106354`) found systematic duration distortions as an event
unfolded: beginnings were compressed, endings expanded, and represented duration changed
across the internal structure of the sequence.

That makes `where am I inside the event?` a variable separate from any putative global
clock speed.

### Remembered boundaries

Yue et al. (Psychonomic Bulletin & Review 2026,
DOI `10.3758/s13423-025-02833-z`) found that the number of recalled subevents/event
boundaries strongly predicted retrospective judgments of whole-event duration, and that
changes in recalled subevent count over a week tracked compression/expansion of duration
judgments.

This is especially relevant to danger because salient/arousing moments can alter event
segmentation and memory organization.

---

## 3. The stronger danger hypothesis is therefore not `more frames`

PresentMoment already contains evidence that arousal can alter event boundaries,
neuromodulation, memory separation, cardiac/respiratory state and body-brain loops.

The free-fall negative result suggests the interesting causal path is more likely to be
something like:

```text
DANGER / AROUSAL
      |
      +--> changed gain / attention
      +--> changed event segmentation
      +--> altered encoding-vs-retrieval balance
      +--> stronger or more distinctive memory traces
      +--> altered body-brain recurrent state
      |
      v
richer / differently partitioned record of the episode
      |
      v
retrospective duration dilation and/or altered passage-of-time judgment
```

rather than

```text
DANGER -> globally faster perceptual sampling
```

This remains a family of hypotheses. It is not established that one particular
segmentation or neuromodulatory mechanism explains the free-fall effect.

---

## 4. Connection to the slow encode/retrieve scheduler hypothesis

Yang, Leopold, Duyn & Liu (Nature Communications 2026,
DOI `10.1038/s41467-026-69068-x`) report multi-second human infra-slow dynamics in which
visual-semantic encoding and memory retrieval vary reciprocally across a propagating
SM-to-DMN activation pattern.

Their discussion speculates that high arousal may interrupt the normal infra-slow cycle
and bias the system toward sustained externally oriented encoding.

That is interesting beside the free-fall result because it offers a possible mechanism
for **richer encoding without better sensory temporal resolution**.

But the connection is currently an inference:

```text
Yang slow/arousal state
    +
Stetson retrospective dilation
    +
event-boundary memory results

DO NOT YET EQUAL

a demonstrated mechanism of fear-time dilation
```

A direct experiment would need simultaneous arousal/state measures, online timing or
resolution measures, event segmentation/memory measures, and later duration judgments.

---

## 5. Consequence for `wide present`

Do not define a biological wide present by asking only

```text
How many milliseconds wide is now?
```

The frightening-event literature makes that increasingly unlikely to be the useful
question.

The better variables are closer to the ones in
`TEMPORAL_ACCESSIBILITY_OPERATOR.md`:

```text
which recent sources are currently potent?
which receivers can access them?
what is being encoded versus retrieved?
where are event boundaries being laid down?
what body/neural phase is modulating those pathways?
what temporal structure will survive into later recall?
```

A scalar duration can change downstream of all of these without a literal extension of
sensory temporal resolution.

---

## Stop rule

Treat the following as **not earned** unless new evidence directly overturns the negative
control:

> `fear makes the present longer because the brain temporarily samples the world at a
> proportionally higher temporal resolution.`

The surviving question is more interesting and more complicated:

> **How does danger reconfigure the state-dependent accessibility, segmentation and
> memory-writing structure of the current brain-body system, and which of those changes
> later becomes experienced or remembered as altered time?**
